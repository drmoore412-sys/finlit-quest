## Why zero new compositions is a useful result

The validation cycle shows that the existing V3 slate already captures the strongest combinations available from the current 147-term governed registry and 21 approved ordinary supporting words. The solver can create multiple legal layouts, but layout variety does not automatically create a new lesson or justify replacing a governed puzzle.

Three distinct outcomes must remain separate:

1. **Valid layout:** the grid satisfies crossing, separation, letter-multiset, vocabulary, majority, contained-word, reward, and engine rules.
2. **Unique composition:** the answer set is not already present in the governed slate.
3. **New educational value:** the composition teaches a useful relationship better than the current puzzle.

A candidate advances only when it passes all applicable gates. Validation alone does not imply uniqueness or approval.
